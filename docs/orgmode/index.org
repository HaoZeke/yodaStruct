======
dseams
======

Lua and Fennel library for the d-SEAMS C++ engine.
#+end_export

* Overview

This repository is a *library*. ~require("dseams")~ in Lua,
~(require :dseams)~ in Fennel. The engine CLI is ~seams~ in
[[https://github.com/d-SEAMS/seams-core][seams-core]]. Python is
[[https://github.com/d-SEAMS/PydSEAMSlib][pydseams]].

#+begin_src lua
local dseams = require("dseams")
local cloud = dseams.read("water.lammpstrj")
print(dseams.chill_plus(cloud, {cutoff = 3.5}))
#+end_src

~dseams.core~ is the compiled registrations (~dseams_core.so~).
Helpers stay in Lua. ~require("yoda")~ still resolves to ~dseams~.
